NEW DORM: DIVIDE

A NEW DORM, AT DUSK AND AT DAWN

CONCEPT

As part of a human centred group design project, I developed a brand and product, which aims to improve student dorm room lifestyle by creating greater distinction between the sleep and work environment, which is often merged in a dorm room. (especially during the height of the COVID Pandemic). The solution was developed through a cycle of user testing and feedback, and implemented pneumatic cylinders to create a collapsible whiteboard that sits next to a bed, blocking the users view and access to the bed while working, and also providing workspace

SLEEP MODE

In sleep mode the board is retracted and locked in downward position. If the user prefers, it can even be kept up while sleeping, to create a pod atmosphere.

WORK MODE

In work mode, the board is unlocked and the pneumatic cylinders cause it to raise up. The board was locked in by a cylindrical pencil case, which can now be used. Not only does the board create a separation between the work and sleep space, reducing temptation to get into bed, but it has a whiteboard surface which can now be used with the pens from the pencil case, further emphasizing this distinction between work and sleep mode, and giving additional workspace.

THE BRAND

The brand which I created for this product was called New Dorm, with tagline 'A New Dorm, at Dusk and at Dawn'. The brand language was friendly and calming, whilst remaining minimalist.
